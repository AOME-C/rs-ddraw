# Plan: 修复尤里的复仇 — 补齐缺失的核心功能

## 根因分析

rs-ddraw 相比 cnc-ddraw 缺少9项关键功能。最可能导致"无法设定显示模式"的原因：

1. **EnumDisplayModes 是空操作** — 游戏查询可用分辨率时得到0个结果，认为没有可用模式
2. **GetDisplayMode 填充不完整** — 缺少 dwSize、dwFlags、像素格式详情
3. **GetCaps 返回空能力** — 游戏可能检查驱动能力
4. **CreateSurface 不处理翻转链** — 不创建 backbuffer，GetAttachedSurface 总是失败
5. **SetDisplayMode 不管理窗口** — 不调整窗口大小、不发送 WM_SIZE

## 修改文件

| 文件 | 修改内容 |
|------|----------|
| `src/ddraw/mod.rs` | 实现 EnumDisplayModes、完善 GetDisplayMode、实现 GetCaps、完善 SetDisplayMode |
| `src/ddraw/surface.rs` | 实现 backbuffer 创建、GetAttachedSurface、Flip、GetDC |

## 详细修改

### 1. EnumDisplayModes — 报告常用分辨率

实现一个硬编码的分辨率列表（参考 cnc-ddraw），通过回调报告给游戏：

```
320x200, 320x240, 640x480, 800x600, 1024x768, 1280x1024
```

每个分辨率报告 8bpp、16bpp、32bpp 三种格式。填充完整的 DDSURFACEDESC：
- dwSize = sizeof(DDSURFACEDESC)
- dwFlags = DDSD_WIDTH | DDSD_HEIGHT | DDSD_PITCH | DDSD_PIXELFORMAT | DDSD_REFRESHRATE
- dwRefreshRate = 60
- lPitch = ((width * bpp + 63) & ~63) / 8
- 完整的 DDPIXELFORMAT（含位掩码）

### 2. GetDisplayMode — 填充完整数据

```rust
fn fill_desc_v1(desc: &mut DDSURFACEDESC) {
    desc.dwSize = std::mem::size_of::<DDSURFACEDESC>() as u32;
    desc.dwFlags = (DDSD_WIDTH | DDSD_HEIGHT | DDSD_PIXELFORMAT) as u32;
    desc.dwWidth = g.width;
    desc.dwHeight = g.height;
    desc.ddpfPixelFormat.dwSize = std::mem::size_of::<DDPIXELFORMAT>() as u32;
    desc.ddpfPixelFormat.dwFlags = DDPF_RGB as u32;
    desc.ddpfPixelFormat.Anonymous1.dwRGBBitCount = g.bpp;
    // 16bpp: 0xF800/0x07E0/0x001F, 32bpp: 0xFF0000/0x00FF00/0x0000FF
}
```

### 3. GetCaps — 报告基本能力

```rust
fn GetCaps(&self, driver: *mut DDCAPS_DX7, emul: *mut DDCAPS_DX7) -> Result<()> {
    // driver caps: DDCAPS_BLT | DDCAPS_PALETTE | DDCAPS_BLTCOLORFILL | DDCAPS_BLTSTRETCH
    // ddsCaps: DDSCAPS_BACKBUFFER | DDSCAPS_FLIP | DDSCAPS_FRONTBUFFER | DDSCAPS_PRIMARYSURFACE | DDSCAPS_VIDEOMEMORY
    // dwVidMemTotal = 16MB, dwVidMemFree = 16MB
}
```

### 4. CreateSurface — 支持翻转链

当 primary surface 带 DDSCAPS_FLIP 时：
- 添加 DDSCAPS_FRONTBUFFER 能力
- 如果 dwBackBufferCount > 0，递归创建 backbuffer surface
- 将 backbuffer 存储在 SurfaceImpl 中

SurfaceImpl 新增字段：
```rust
pub backbuffer: Option<IDirectDrawSurface>,
pub is_backbuffer: bool,
```

### 5. GetAttachedSurface — 返回 backbuffer

当请求 DDSCAPS_BACKBUFFER 时，返回存储的 backbuffer surface。

### 6. Flip — 交换 front/back 像素缓冲区

### 7. GetDC — 创建兼容 HDC

使用 CreateCompatibleDC + CreateDIBSection 创建 HDC，允许游戏通过 GDI 绘制。
